# Community Feedback

Useful feedback includes:

- installation problems;
- launch/runtime issues;
- scan behaviour;
- metadata accuracy;
- duplicate-analysis behaviour;
- usability observations;
- performance observations;
- unexpected warnings or errors;
- feature requests.

When possible include:

- DAMS version;
- Windows version;
- approximate resource count;
- approximate library size;
- local or OneDrive-backed source;
- reproduction steps;
- exact error message.

Do not attach private media, credentials or sensitive personal information to public reports.
