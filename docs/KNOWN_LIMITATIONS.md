## Platform

- Windows desktop only.
- iOS and Android applications are not included.
- No hosted/cloud control plane is included.

## Resource scope

The primary supported use case is personal photo and video analysis.

Document intelligence, structured-data intelligence, archive intelligence and the future universal digital-resource model are not part of v1.0.0.

## Duplicate intelligence

v1.0.0 focuses on exact duplicate evidence.

Visual similarity, edited-copy identification and semantic near-duplicate detection are not included.

## Performance

Processing duration depends on resource count, data volume, storage performance, OneDrive availability, metadata complexity and hardware capability.

Large libraries may require significant processing time.

## Connectivity

The generalized connector framework planned for future DAMS editions is not part of v1.0.0.
