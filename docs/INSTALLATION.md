# Installing DAMS Community Edition

## Supported release

DAMS Community Edition v1.0.0

## Installation

1. Open the GitHub Releases section.
2. Download DAMS_Community_Edition_1.0.0_Setup.exe.
3. Verify the SHA-256 checksum if desired.
4. Run the installer.
5. Complete installation.
6. Launch DAMS Community Edition.
7. Select a media source you are authorised to analyse.
8. For your first test, preferably use a smaller or backed-up library.

## First-run checks

Confirm that:

- DAMS launches successfully;
- a media source can be selected;
- analysis completes;
- Library and Reports display results;
- no unexpected source files are modified.

## Important

Maintain backups of valuable digital resources.
