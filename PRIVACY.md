DAMS Community Edition follows a local-first media-management approach.

The core Community workflow is designed to analyse user-selected media using local application/runtime resources rather than requiring upload of the media library to an external AI service.

Library analysis can generate local technical information including inventory records, hashes, metadata summaries, duplicate evidence and runtime reports.

Users should protect those outputs according to the sensitivity of the underlying media.

Future optional connectors or DAMS editions may have different processing requirements and must define their own authorization, privacy and security controls.
