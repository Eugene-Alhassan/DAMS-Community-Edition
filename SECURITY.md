# Security

## Release integrity

Obtain official Community Edition release assets from the DAMS Community Edition GitHub Releases page and verify the published SHA-256 checksum.

## Safe testing

- Analyse only resources you are authorised to access.
- Maintain backups of valuable files.
- Do not publish sensitive generated reports.
- Do not include private media or credentials in public bug reports.

A dedicated security reporting process may be introduced in a future release.
